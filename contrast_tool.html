Contrast Billing Export Tool

Turns the Epic contrast-exam report into a billing feed: keeps only exams with a contrast agent given by a recognized CAMRIS technologist, and reshapes it into the CAMRIS-003 charge format. Runs entirely in your browser — no files are uploaded anywhere.

How this is built

1. Start from Contrast_Report.csv and keep only rows where Procedure-Related Meds is not blank (contrast was actually given).
2. Keep only rows whose Technologist matches a name in CAMRIS_Technologists.csv (an inner join on technologist name — exams performed by technologists not on that list are dropped, and technologists with no matching exams don't produce a row).
3. Begin Exam Time (format m/d/yy H:MM) is split into a date (yyyy-mm-dd) and event_time (HH:MM, 24-hour) column.
4. Columns are renamed/added: Linked Study IRB Number→project, PennKey→userid, Accession #→specimen, Provider/Resource→desc2, plus fixed columns lab=7, sublab=0, code=CAMRIS-003, desc1="Contrast Injection", quantity=1, bill=Y.
