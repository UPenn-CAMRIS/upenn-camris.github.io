Intermediate steps & column reference

dfmerge: Dogfish events grouped by Event ID (no-show/cancellation rows removed; each service type OR‑reduced into a boolean column).
dfmergewithcams: left-joined to CAMS_Data.csv on Protocol Number to pull in Industry Sponsored.
dfmergewithcamsredcap: left-joined to the RedCap export (rows with camris_review_letter_complete == 2, grouped by IRB number, last value kept) to pull in RedCap Neuroreader / RedCap Stimulus.
audit_output: every row with at least one TRUE or unknown (blank) error flag.
audit_output_unique: audit_output reduced to Protocol Number + the 8 error columns, de‑duplicated — this matches the original script's final CSV.
